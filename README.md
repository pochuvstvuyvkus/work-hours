# Учёт часов

Одностраничник для учёта рабочих часов по проектам: дата, проект, часы, ставка (по умолчанию 1000 ₽/ч). Считает суммы за день, месяц и всё время, разбивку по проектам, выгружает CSV для Excel.

Записи хранятся в браузере (localStorage) и в репозиторий не попадают. Для переноса между устройствами есть «Сохранить копию» и «Загрузить копию».
