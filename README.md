# Учёт часов

Одностраничник для учёта рабочих часов по проектам: дата, проект, часы, ставка (по умолчанию 1000 ₽/ч). Считает суммы за день, месяц и всё время, разбивку по проектам, выгружает CSV для Excel.

- Записи лежат в `data.json` в этом репозитории. Страницу видят все, у кого есть ссылка.
- Добавлять и менять записи может только владелец ключа GitHub с правом записи в репозиторий (кнопка «Войти для записи»).
- Каждое изменение сохраняется отдельным коммитом с описанием «было / стало», список виден на странице в блоке «История изменений».
