Вход для записи

Записи сохраняются в репозиторий GitHub, поэтому для записи нужен ключ доступа GitHub. Его видит только этот браузер.
  1. Создайте ключ на GitHub (Fine-grained token).
  2. Repository access: «Only select repositories», выберите .
  3. Permissions, Repository permissions: «Contents» поставьте «Read and write».
  4. Нажмите «Generate token», скопируйте ключ и вставьте ниже.
